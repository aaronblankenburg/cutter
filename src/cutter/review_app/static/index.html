    How to use

    SpacePlay / pause
    J · K · Lbackwards · stop · forwards (press again: faster)
    , · .1 frame back · 1 frame forward
    ← · →2 s back · 2 s forward
    Shift + ← · →previous · next shot
    SEdit preview: loop from 2 s before to 2 s after the nearest edit
    ZZoom: timeline ±20 s around the current position
    NWrite a note (the video pauses)
    I · ORange start · end for the next comment
    X“Remove” for the current position
    EscEnd range and edit preview
    ?this help
    Capital letterstarts a note, even without clicking into the field (the video pauses)
